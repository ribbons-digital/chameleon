## Optional follow-up thread

1. WebMCP lets a web page register typed, described tools that agents call directly. No screen-scraping, no guessing at buttons. ChatGPT's desktop browser supports it now, and Chrome's origin trial runs through Chrome 156.

2. The bit we're proudest of: when the agent builds a form in Chameleon, the page registers a new WebMCP tool whose schema comes from that form's fields. "Log a reading of 104 after lunch" becomes one validated tool call. The agent extends the app's own API.

3. Built for the OpenAI WebMCP Challenge with React 19, Zod 4, Zustand, and Cloudflare Workers. MIT licensed, source here: https://github.com/ribbons-digital/chameleon

4. If your customers' agents are fumbling your checkout or booking flow today, WebMCP is how you fix that. We wrote up who should adopt it and how to start: <BLOG_URL>
